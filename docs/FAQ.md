# 常见问题 FAQ

## 运行与模型

### 首次启动为什么要下载很久？

应用不打包约 2GB 的 CosyVoice3 权重。点击「初始化模型」后会从 Hugging Face 下载到本机缓存，仅需一次。请预留磁盘与稳定网络；下载中断可再次点击初始化续传（取决于上游缓存行为）。

### 必须是 Apple Silicon 吗？

是。推理依赖 MLX / Metal，**不支持 Intel Mac**。

### 内存占用很大正常吗？

正常偏高。MLX 会积极缓存，峰值可达数 GB。建议 16GB 内存以上；导出或批量合成时尽量不要同时开多个吃内存的应用。

### 可以离线使用吗？

模型下载完成后可离线合成与导出。仅首次下载模型、以及你主动访问网络的功能需要联网。

## EPUB 与章节

### 为什么有的书章节很少 / 标题怪？

电子书制作质量差异很大。当前策略：

- 有可靠锚点时按目录「节」切分
- 目录与正文错位时，以**正文首行**为准，并尽量回填卷/章层级
- 无目录则按文件顺序整文件成章

可用下面命令对单本书做无头诊断（打印每章标题与字数）：

```bash
# 构建 Debug 后
path/to/abm.app/Contents/MacOS/abm --verify-epub-split /path/to/book.epub
```

### 升级后书架书「消失」并提示重新导入？

章节清单结构升级会导致旧 `book.json` 无法解码。用**原 EPUB 重新导入**即可（会覆盖目录结构；音频需重新合成）。数据目录在覆盖前仍保留。

### 支持哪些格式？

目前专注 **EPUB** 导入；也可用「快速单文本」粘贴纯文本合成。

## 导出

### 导出没有章节标记？

请使用 **M4B** 导出。需要本机构建过内置 ffmpeg：

```bash
scripts/build-ffmpeg.sh
```

缺少该组件时 M4B 会明确报错，而不是静默导出无章节文件。

### 能导出 MP3 吗？

目前提供 **M4B / 分章 M4A / WAV**。macOS 无系统 MP3 编码器，项目有意不引入额外编码依赖（见规格说明）。

### 如何在 Apple Books 里看到章节？

导出 M4B 后用访达打开或拖入 Books。若系统阅读器读不到章节，可用 `ffprobe` 交叉验证文件内是否已有章节流。

## 开发

### 如何参与？

见 [CONTRIBUTING.md](../CONTRIBUTING.md)。从 good first issue、文档、EPUB 解析夹具入手最合适。

### 规格驱动是什么意思？

行为变更先写 `openspec/changes/` 提案，再实现。主规格在 `openspec/specs/`。

### Archive 失败 / Float16 错误？

已通过本地 `Vendor/speech-swift`（float32 补丁）修复 GUI Archive。若仍遇到，请删 DerivedData 后重试，并附完整日志。
