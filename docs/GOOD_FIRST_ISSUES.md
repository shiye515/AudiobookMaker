# Good first issues 说明（维护者）

在 GitHub 上给适合新人的 Issue 打上标签，可加速协作。

建议标签：

| Label | 颜色建议 | 用途 |
|-------|----------|------|
| `good first issue` | 绿色 | 有明确范围、无需啃推理栈 |
| `help wanted` | 蓝色 | 希望社区认领 |
| `epub` | 紫色 | 解析 / 章节相关 |
| `export` | 橙色 | M4B / M4A / WAV |
| `docs` | 浅灰 | 文档与 FAQ |
| `bug` | 红色 | 缺陷 |
| `enhancement` | 浅蓝 | 功能增强 |

## 适合标成 good first issue 的题目（可直接开 Issue）

1. **书架空态文案与图标**打磨  
2. **章节表格**列宽 / 排序（按字数、状态）  
3. **FAQ** 增补真实用户问题  
4. **夹具**：再加一本畸形 NCX 的迷你 EPUB 进 `scripts/make_epub_fixtures.py`  
5. **导出文件名**在超长层级下的截断策略说明  

开 Issue 时写清：验收标准、涉及文件、是否需要真机音频。
