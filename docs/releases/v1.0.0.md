# AudiobookMaker v1.0.0

首个开源版本：在 Mac 上把 EPUB 全程离线转换成结构完整的 M4B 有声书。

## 亮点

- 导入并解析 EPUB 书籍、章节、封面与元数据
- 使用 macOS 系统语音或 Kokoro 本地 AI 音色生成音频
- 展示书籍及当前章节转换进度，支持暂停和恢复
- 导出单个 M4B 文件，内嵌章节导航、封面和书籍元数据
- 生成标准 M4B，兼容播放器的书签、同步与不变调变速功能
- Universal 2 构建，同时支持 Apple 芯片与 Intel Mac

## 下载

下载 `AudiobookMaker-1.0.0-macOS-universal.zip`，解压后将应用拖入“应用程序”。可使用同页的 `.sha256` 文件验证下载完整性。

系统要求：macOS 26.0 或更高版本。

## 签名与公证

此版本使用 Developer ID Application 证书签名、启用 Hardened Runtime，并已通过 Apple 公证与 Gatekeeper 验证。

模型权重未包含在安装包内。Kokoro 模型只会在用户主动操作后下载，并在本机完成推理。
