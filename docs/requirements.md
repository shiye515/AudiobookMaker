# AudiobookMaker 需求文档

> 版本：v0.1（初稿，待设计阶段细化）
> 状态：需求确认中
> 适用范围：macOS 原生 App（SwiftUI + SwiftData）

---

## 1. 产品概述

AudiobookMaker 是一款 macOS 桌面应用，帮助用户将 **EPUB 格式电子书** 转换为 **有声书音频文件**。核心流程为：导入 EPUB → 解析分章 → 调用本地 TTS 模型逐章转语音 → 封装为带封面与文本轨的 M4B 音频 → 管理转换任务 → 打包导出。

应用定位为「本地优先、隐私友好」：所有推理在用户本机完成，书籍内容不上传云端。

---

## 2. 业务场景与核心流程

1. 用户在「书籍管理」中导入一本 EPUB 电子书。
2. 应用解析 EPUB，提取纯文本并按章节切分，生成书籍记录与章节列表，同时从 EPUB 中提取封面图。
3. 用户在「模型管理」中选择当前使用的 TTS 模型（默认模型为 CosyVoice3 0.5B）。
4. 用户手动启动某本书的转换任务；任务进入队列，按并发上限排队执行。
5. 转换过程中可暂停 / 继续；支持断点续传（关闭 App 后重开可继续未完成的章节）。
6. 每章转换完成后，封装为一个独立的 M4B 文件：包含音频、章节标记、封面、整段文本轨（无逐句时间戳）。
7. 整本书所有章节转换完成后，用户可将其打包导出（按常规做法：整本书章节 M4B 打包为 zip 归档）。

## 3. 功能需求

### 3.1 书籍管理（Book Management）

| 编号 | 功能 | 说明 |
|------|------|------|
| FR-1.1 | 导入 EPUB | 支持文件选择 / 拖拽导入 `.epub` 文件 |
| FR-1.2 | EPUB 解析 | 仅提取**纯文本**，按**章节（spine / nav 结构）**切分为章节列表；不处理图文混排、表格、脚注（超出范围） |
| FR-1.3 | 封面提取 | 从 EPUB 的封面元数据 / 资源中提取封面图，用于音频封装与界面展示 |
| FR-1.4 | 书籍列表 | 查看所有已导入书籍（标题、作者、封面缩略、章节数、总进度、状态） |
| FR-1.5 | 章节列表 | 查看单本书的章节列表及每章状态（待转换 / 转换中 / 已完成 / 已暂停） |
| FR-1.6 | 任务控制 | 手动**开始**某本书的转换；支持**暂停 / 继续**当前任务 |
| FR-1.7 | 并发与排队 | 多本书可加入队列；按**并发上限**排队执行（并发数待定，默认建议 1~2） |
| FR-1.8 | 断点续传 | 已完成的章节结果持久化；App 重启后未完成任务可从已完成处继续，无需重转 |
| FR-1.9 | 删除书籍 | 删除书籍记录及其已生成的音频产物（需确认是否一并删除源文件） |

### 3.2 模型管理（Model Management）

| 编号 | 功能 | 说明 |
|------|------|------|
| FR-2.1 | 模型列表 | 展示已安装 / 可切换的开源 TTS 模型 |
| FR-2.2 | 模型切换 | 在**不同 TTS 框架**的模型间切换（多框架适配，见 §4） |
| FR-2.3 | 默认模型 | 首次启动默认使用 `FunAudioLLM/Fun-CosyVoice3-0.5B-2512`（ModelScope 仓库） |
| FR-2.4 | 模型状态 | 显示模型加载状态、所属框架、基本参数（语音参数本期先用默认值，见 FR-2.5） |
| FR-2.5 | 语音参数（默认） | 音色 / 语速 / 语调本期使用模型默认，界面预留配置入口但暂不实装复杂配置 |

> 注：本地推理运行时的具体架构（如何拉起模型、进程管理、资源占用）**不在本期设计范围内**，App 仅通过约定的接口边界与之交互（见 §6）。

### 3.3 音频封装与导出（Audio & Export）

| 编号 | 功能 | 说明 |
|------|------|------|
| FR-3.1 | 章节音频格式 | 每章输出一个 **M4B** 文件 |
| FR-3.2 | 章节标记 | M4B 内写入章节标题 / 章节标记（chapter marker） |
| FR-3.3 | 封面嵌入 | 将 EPUB 封面图嵌入 M4B 元数据 |
| FR-3.4 | 文本轨 | 将**整段章节文字**作为一个文本轨写入 M4B（无逐句时间戳，P2 阶段先简单做） |
| FR-3.5 | 打包导出 | 已转换完成的书籍，将其所有章节 M4B **打包为 zip 归档**导出（常规做法） |
| FR-3.6 | 导出内容 | 归档内建议包含：各章节 M4B、书籍元数据（书名/作者/封面）说明文件 |

## 4. 多框架适配说明

模型管理需支持**不同 TTS 框架**的模型切换（非仅同框架换权重）。已知框架示例：

- **CosyVoice 系列**（如 CosyVoice3 0.5B，PyTorch 推理）
- 其他开源 TTS 框架（如 Bark / FishSpeech / GPT-SoVITS 等，后续扩展）

适配策略（设计阶段细化）：App 侧定义统一的 **TTS 抽象接口**（输入文本 + 参数 → 输出音频流/文件），各框架通过适配层接入。本期至少保证 CosyVoice3 0.5B 跑通，接口预留多框架扩展点。

## 5. UI 结构（ASCII 草图）

整体采用 **三栏 + 模态/面板** 布局（macOS 风格）。左侧导航切换「书籍管理 / 模型管理」，中间为内容区，右侧为详情/任务面板。

```
|  Toolbar: [导入EPUB]  [+]  [设置]                                         |
+------------+--------------------------------------------------+----------+
|  侧边导航   |                  内容区 (Content)                  | 详情面板  |
|            |                                                  |          |
|  ┌────────┐ |  ┌────────────────────────────────────────────┐ | ┌──────┐ |
|  │ 书籍管理 │ |  │  书籍列表 / 章节列表 (依导航切换)          │ | │ 选中 │ |
|  ├────────┤ |  │                                            │ | │ 书籍 │ |
|  │ 模型管理 │ |  │  --------------------------------------   │ | │ 详情 │ |
|  └────────┘ |  │  书籍卡片: 封面 | 标题 | 进度条 | 状态      │ | │      │ |
|            |  │  章节行:  标题 | 状态 | [开始/暂停/继续]     │ | │ 任务 │ |
|            |  │                                            │ | │ 控制 │ |
|            |  └────────────────────────────────────────────┘ | └──────┘ |
|            |                                                  |          |
|            |  模型管理视图:                                   |          |
|            |  ┌────────────────────────────────────────────┐ |          |
|            |  │ 模型卡片: 名称 | 框架 | 状态 | [切换/默认] │ |          |
|            |  └────────────────────────────────────────────┘ |          |
+------------+--------------------------------------------------+----------+

底部状态栏: 队列状态 | 当前并发 | 全局进度
+--------------------------------------------------------------------------+
```

### 5.1 主要视图说明

- **书籍管理视图**
  - 顶部：导入按钮、搜索/筛选。
  - 主体：书籍列表（封面缩略 + 标题 + 总进度 + 状态徽标）。
  - 进入单书：章节列表，每章带状态与开始/暂停/继续控制。
- **模型管理视图**
  - 模型卡片列表，展示框架、加载状态，支持「设为默认」「切换使用」。
- **详情/任务面板（右侧）**
  - 展示选中书籍的元信息、当前任务进度、队列位置、暂停/继续入口。
- **底部状态栏**
  - 全局队列概览：排队中 / 转换中 / 已完成数量，当前并发占用。

## 6. App 与本地推理运行时的交互边界（本期不设计实现）

> 本地推理运行时（如何加载 CosyVoice3 等模型、进程/资源管理）**不在本期范围内**。App 仅定义如下交互契约，供后续设计：

- **接口形态（待定，建议）**：本地 HTTP/gRPC 服务，或进程内桥接。App 发送「文本 + 模型标识 + 参数」请求，接收音频数据。
- **能力要求**：
  - 给定文本片段，返回对应音频（WAV/PCM 或编码后）。
  - 支持按章节粒度请求，便于断点续传与暂停。
  - 模型加载/卸载、切换由运行时负责，App 通过状态接口查询。
- **错误与取消**：请求可取消（对应暂停），超时/失败需返回明确错误供 App 重试或标记失败。

## 7. 数据模型（SwiftData，概要）

> 设计阶段细化字段与关系，此处仅列实体。

- **Book**：书名、作者、封面数据、源文件路径、导入时间、总状态、总进度。
- **Chapter**：所属 Book、序号、标题、原文文本、状态（待转换/转换中/已完成/已暂停/失败）、对应 M4B 文件路径、音频时长。
- **TTSModel**（或 ModelEntry）：标识、名称、框架类型、默认标记、状态、本地路径/来源。
- **TaskQueue / Job**（可选）：队列项、并发控制、断点续传游标。

---

## 8. 非功能需求

- **隐私**：所有处理本地完成，无云端上传。
- **持久化**：书籍、章节、任务进度使用 SwiftData 持久化，支持重启后恢复。
- **性能**：转换为耗时操作，须后台执行，不阻塞 UI；大本书籍内存可控。
- **可扩展性**：模型管理为多框架预留扩展点；EPUB 解析后续可增强（图文/表格）。

## 10. 里程碑建议（供设计参考）

1. **M1 骨架**：SwiftData 数据模型 + 三栏 UI 框架 + 书籍/模型导航。
2. **M2 导入与解析**：EPUB 导入、纯文本分章、封面提取、书籍列表展示。
3. **M3 模型管理**：模型列表、切换、默认模型、与运行时交互边界联调（CosyVoice3 0.5B）。
4. **M4 转换与任务**：队列/并发/暂停继续/断点续传、章节状态流转。
5. **M5 封装与导出**：M4B 封装（章节标记+封面+文本轨）、zip 打包导出。
6. **M6 打磨**：错误处理、状态栏、空态/异常态、基础测试。
