# Design: 音色中心 UI 视觉与交互全面重构

## 架构与视觉设计

### 1. Header 与分类筛选区
- 布局：VStack 组织 Header 标题栏与分类筛选行。
- Header：大标题“音色中心”，副标题“精选 10 款有声书专属声线，支持试听采样与设为默认旁白”。
- Pill 分类栏：自定义胶囊按钮，显示各分类当前音色数量（如“全部 10”、“男声 4”、“女声 6”），选中态配合平滑动画背景。
- 搜索框：现代药丸胶囊输入框，带放大镜与快速清空图标，支持实时多字段匹配（名称、特质、样例文本）。

### 2. 卡片重构（VoiceCardView）
- 材质：14pt 圆角，层次背景（自适应深浅模式），0.5pt 细腻边框，Hover 悬停微升（-2pt offset + 扩散柔和微阴影）。
- 默认旁白指示：右上角展示精致胶囊徽章（带 `checkmark.seal.fill` 图标），整卡带柔和 AccentColor 细边框；非默认音色卡片提供克制轻量按钮。
- 头像体系：根据音色特质映射精选渐变色系（藏青、蜜桃粉、琥珀橙、松柏绿、暖茶红等），结合声波/麦克风矢量图腾；播放时产生呼吸脉冲扩散动画。
- 文学名篇台词框（VoiceQuoteBox）：以轻微半透明底框展示该音色经典采样名句，带书卷感。
- 动态频谱试听控制条（VoicePreviewBar）：集成播放/停止按钮、动态跳动频谱波形（`AnimatedSpectrumWaveform`）、状态指示。
